# Evaluation set

Put 20–25 executives in `people.csv` (columns: name,title,company).
Mix them on purpose:
- ~8 very well-known CEOs (lots of public info — tests precision)
- ~12 lesser-known CFOs / CTOs of S&P 500 companies (sparse info — tests abstention)
- 2–3 people with common names (tests identity disambiguation)

Pull names from company leadership pages and double-check the current title before adding.
Only hand-graded numbers (C/W/U/M) go on a resume — never the auto metrics alone.
